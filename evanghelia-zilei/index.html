❓ Întrebări frecvente

Care este evanghelia zilei de azi? +
Evanghelia zilei de azi este afișată mai sus: cartea, versetele și linkul către textul oficial.
Evanghelia zilei doxologia — unde o găsesc? +
Evanghelia zilei o găsești chiar aici, pe povestidecredinta.ro, cu cartea, versetele și linkul către textul oficial. Pagina se actualizează zilnic conform Tipicului Bisericii Ortodoxe Române.
Evanghelia zilei de azi audio — unde o ascult? +
Evanghelia zilei în format audio o găsești pe canalul nostru YouTube @povestidecredinta. Abonează-te pentru a primi zilnic notificări cu Evanghelia, Apostolul și rugăciunile zilei.
Evanghelia zilei duminica — ce se citește? +
Duminica, Evanghelia se citește din ciclul celor 11 Evanghelii ale Învierii (Eothinale), care se repetă ciclic. Fiecare duminică are o Evanghelie specifică despre arătările Mântuitorului după Înviere. Pe această pagină, Evanghelia duminicii este afișată automat în ziua respectivă.
Evanghelia și apostolul zilei — unde le citesc împreună? +
Pe Calendar Ortodox Azi găsești Evanghelia și Apostolul zilei împreună, alături de sfântul zilei, tipul de post și culoarea liturgică — totul pe o singură pagină.
