Sinaxarul zilei

Intrebari frecvente despre Sinaxar

Ce este Sinaxarul in Biserica Ortodoxa? +
Sinaxarul este cartea liturgica ortodoxa care cuprinde vietile sfintilor prazanuiti in fiecare zi a anului, citite la Utrenie. Cuvantul vine din grecescul synaxis (adunare).
Cum se deosebeste Sinaxarul de Mineiu? +
Mineiurile sunt carti liturgice lunare care contin slujbele complete ale sfintilor, in timp ce Sinaxarul cuprinde doar vietile sfintilor, citite ca lectura la Utrenie.
De ce este importanta cunoasterea vietii sfintilor? +
Vietile sfintilor sunt exemple concrete de implinire a Evangheliei in viata cotidiana. Ele ne inspira, ne intaresc credinta si ne arata ca sfintenia este posibila pentru orice crestin.

Apostolul zilei

Intrebari frecvente despre Apostol

Ce este Apostolul in cadrul Sfintei Liturghii? +
Apostolul este pericopa din Epistolele Apostolice citita la Sfanta Liturghie inainte de Evanghelie, conform randuielii liturgice ortodoxe.
De ce se citeste Apostolul la Liturghie? +
Apostolul face parte din Liturghia Cuvantului. Prin el, credinciosii asculta invatatura apostolica si sunt pregatiti pentru primirea Cuvantului lui Dumnezeu din Evanghelie.
Ce este o pericopa apostolica? +
Pericopa apostolica este un fragment din Epistolele Apostolice, selectat de Tipicul Bisericii pentru a fi citit intr-o anumita zi liturgica.

Evanghelia zilei

Intrebari frecvente despre Evanghelie

Ce este Evanghelia zilei in calendarul ortodox? +
Evanghelia zilei este pericopa din una dintre cele patru Evanghelii randuita de Tipicul Bisericii pentru a fi citita la Sfanta Liturghie in ziua respectiva.
De ce se citeste Evanghelia in picioare? +
Credinciosii stau in picioare la citirea Evangheliei ca semn de respect fata de Cuvantul lui Dumnezeu si ca pregatire pentru primirea lui Hristos in Sfanta Euharistie.
Ce reprezinta cele patru Evanghelii? +
Cele patru Evanghelii (Matei, Marcu, Luca, Ioan) sunt marturiile inspirate ale vietii, invataturii, mortii si invierii Mantuitorului Iisus Hristos, scrise de Sfintii Evanghelisti.

Predica zilei

Intrebari frecvente despre Predica

Ce este predica in cadrul Sfintei Liturghii? +
Predica este cuvantul de invatatura rostit de preot sau episcop dupa citirea Evangheliei, prin care se talcuiesc textele scripturistice si se aplica la viata crestinilor.
Ce este talcuirea patristica a Evangheliei? +
Talcuirea patristica este interpretarea Evangheliei de catre Sfintii Parinti ai Bisericii (Sf. Ioan Gura de Aur, Sf. Chiril al Alexandriei etc.), care constituie traditia vie a Bisericii.
Ce este omilia crestina? +
Omilia (din gr. homilia = convorbire) este un tip de predica care urmareste pas cu pas textul scripturistic, comentand si explicand fiecare verset in parte.
