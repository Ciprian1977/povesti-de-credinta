❓ Întrebări frecvente

Care este apostolul zilei de azi? +
Apostolul zilei de azi este afișat mai sus cu textul complet, cartea și versetele.
Apostolul zilei doxologia — unde îl găsesc? +
Apostolul zilei îl găsești chiar aici, pe povestidecredinta.ro, cu textul complet, cartea, versetele și o scurtă tâlcuire. Pagina se actualizează zilnic conform Tipicului Bisericii Ortodoxe Române.
Evanghelia și apostolul zilei — unde le citesc împreună? +
Pe povestidecredinta.ro găsești atât Apostolul zilei cât și Evanghelia zilei pe pagini dedicate, cu textul complet și tâlcuire. Pe Calendar Ortodox Azi le găsești pe amândouă într-o singură pagină.
Ce este Apostolul în slujba ortodoxă? +
Apostolul este o lectură din Epistolele Sfinților Apostoli (sau din Faptele Apostolilor) care se citește la Sfânta Liturghie, înaintea Evangheliei. Fiecare zi din an are rânduit un Apostol specific, conform Tipicului Bisericii Ortodoxe. Apostolul se citește de către diacon sau de un cititor, cu fața spre credincioși.
