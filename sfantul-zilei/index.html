❓ Întrebări frecvente

Ce sfânt este azi? +
Sfântul zilei de azi este afișat mai sus, conform Calendarului Ortodox Român 2026 editat de Patriarhia Română. Fiecare zi are unul sau mai mulți sfinți prăznuiți conform Sinaxarului BOR.
Care este sfântul ortodox de azi? +
Sfântul ortodox de azi este afișat în timp real la începutul acestei pagini. Calendarul nostru este sincronizat cu Calendarul Ortodox Român 2026 publicat de Patriarhia Română. Poți verifica și pe pagina de calendar pentru toate zilele lunii.
Ce sfânt este pe data de azi în calendarul ortodox? +
Conform Calendarului Ortodox Român, sfântul zilei de azi este afișat în secțiunea principală a paginii. Pagina se actualizează automat la miezul nopții pentru a afișa sfântul zilei următoare.
Este post azi în calendarul ortodox? +
Informația despre post pentru ziua de azi este afișată în cardul sfântului de mai sus. Zilele de post ortodox sunt miercurea și vinerea, plus perioadele de post mare (Postul Mare, Postul Sfinților Apostoli, Postul Adormirii Maicii Domnului, Postul Crăciunului).
