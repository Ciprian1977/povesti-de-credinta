❓ Întrebări frecvente

Ce sfânt este azi în calendarul ortodox? +
Sfântul zilei de azi este afișat în cardul principal de mai sus.
Calendar ortodox azi — ce înseamnă culoarea liturgică? +
Culoarea liturgică indică tipul slujbei: alb — sărbători ale Mântuitorului și ale Maicii Domnului; roșu — sfinții mucenici; verde — cuvioși și mărturisitori; vișiniu — post și pocăință; auriu — sfinții ierarhi și apostoli.
Este post azi în calendarul ortodox 2026? +
Informația despre post pentru ziua de azi este afișată în cardul principal. Zilele de post ortodox sunt miercurea și vinerea, plus perioadele de post mare.
Apostolul și evanghelia zilei — unde le găsesc? +
Apostolul și Evanghelia zilei le găsești pe această pagină în cardurile de mai sus, sau pe paginile dedicate: Apostolul Zilei și Evanghelia Zilei, cu textul complet și tâlcuire.
Calendar ortodox azi doxologia — alternativă? +
povestidecredinta.ro este alternativa completă pentru calendarul ortodox zilnic: sfântul zilei, sinaxarul, apostolul, evanghelia, predica zilei, rugăciunile și acatistele — toate pe un singur site, optimizat pentru mobil, cu design curat și fonturi mari pentru o lectură confortabilă.
